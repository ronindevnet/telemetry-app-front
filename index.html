Servidor está offline

Não foi possível conectar à API de telemetria em http://127.0.0.1:5000.

Para inicializar o servidor no Windows, dê um duplo-clique no run.bat da pasta telemetry_app_api. Ou, com o ambiente virtual ativado, execute no terminal:

cd telemetry_app_api
flask run --host 0.0.0.0 --port 5000

Com o servidor no ar, clique em Tentar novamente.
